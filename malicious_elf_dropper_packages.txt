# version: 3
# July 2026 ELF dropper / AUR package takeover campaign
#
# A new wave of malicious AUR packages was uploaded starting 2026-07-29,
# mostly via orphan-package adoption followed by a "Fix source" commit that
# adds a small (~50KB) malicious ELF binary (named 'validator', 'assembler',
# 'optimizer', 'converter', 'hasher', 'packer', 'indexer', etc.) and executes
# it with 'sudo' from the PKGBUILD build() function. The binary contains
# command-execution (system/execl) and network (socket/connect) capabilities
# with obfuscated strings, and is intended to run with root privileges.
#
# AUR registration and package adoption were disabled by Arch DevOps while
# the cleanup was handled. This current blocklist keeps entries whose latest
# audit is still flagged, or whose current package has not been analyzed yet.
# Entries are removed once a current scan is clean; this avoids blocking safe
# replacements while retaining packages that still need manual review.
#
# Sources:
# - Saren / Arch Linux CN, aur-audit (wtako.net), black-flagged packages
#   https://wtako.net/services/aur-audit  (API: https://aur-audit.wtako.net)
# - AUR report thread, "AUR Malware that still presents as of now",
#   2026-07-30 (package/ELF-binary pairs)
#   https://lists.archlinux.org/archives/list/aur-general@lists.archlinux.org/message/P4WIRHTFNH2YZWQHGBAKQWX5YOAFIDLY/
